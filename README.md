# 🔐 Мой Сейф — личный бизнес-ассистент

**«Мой Сейф»** — веб-приложение (личный кабинет) для предпринимателя и продавца: финансовый учёт, умный калькулятор прибыли, мини-CRM со сделками, отчёты, задачи, цели, календарь и ИИ-ассистент. Полностью **бесплатно**, без сервера и внешних библиотек — данные хранятся в браузере пользователя. Устанавливается на телефон как приложение (PWA) и работает офлайн.

> Проект по информатике. Открыл ссылку → зарегистрировался → пользуешься.

## ✨ Возможности

| Раздел | Что делает |
|---|---|

| **Отчёты (P&L)** | Отчёт о прибыли за месяц, налог, динамика к прошлому месяцу, расходы по категориям, **прогноз прибыли**, экспорт CSV и печать в PDF. |
| **Задачи** | Приоритеты, сроки, статусы, фильтры, прогресс. |
| **Цели** | Финансовые цели с прогресс-баром, пополнением и расчётом «сколько откладывать в месяц». |

| **Настройки** | Профиль, валюта, темы (светлая/тёмная/**авто**), **акцентные цвета**, компактный режим, подключение внешнего ИИ, **напоминания**, установка приложения, экспорт/импорт, удаление аккаунта. |

## 📱 PWA — приложение на телефон

- Открывается как обычное приложение (без адресной строки), есть иконка на домашнем экране.
- Работает **офлайн** после первого открытия (service worker).
- Установка: iPhone — «Поделиться» → «На экран Домой»; Android/Chrome — меню → «Установить приложение».

---

## 🤖 Про ИИ (и почему это бесплатно)

- **По умолчанию** — **локальный ИИ-помощник**: разбирает запрос по ключевым словам и отвечает по вашим реальным данным. Интернет и API-ключи не нужны — 0 ₽.
- **Опционально** в «Настройках» можно подключить внешний ИИ (OpenRouter с бесплатными моделями или любой OpenAI-совместимый API). Ключ хранится только в вашем браузере.

## 🚀 Как запустить

### Вариант 1 — просто открыть файл
Откройте `index.html` в браузере. Всё работает офлайн (кроме внешнего ИИ).

### Вариант 2 — локальный сервер
```bash
# из папки проекта
python3 -m http.server 8080
# или
node server.mjs ./ 8080
```
Затем откройте http://127.0.0.1:8080

### Вариант 3 — демо-данные
На экране входа нажмите **«▶ Посмотреть демо»** или откройте `?demo=1`.

## 🌍 Как выложить навсегда (бесплатно)

1. **Netlify Drop** — https://app.netlify.com/drop, перетащите папку `moi-seif` (или zip). Получите адрес `*.netlify.app`.
2. **Cloudflare Pages** — https://dash.cloudflare.com → Workers & Pages → Upload assets.
3. **GitHub Pages** — репозиторий должен быть **публичным**: Settings → Pages → Deploy from a branch → main → /(root).
4. **Vercel** — импорт репозитория, Framework: Other, без сборки.

Никаких сборок и зависимостей — это статический сайт.

## 🧱 Технологии

- **HTML5 + CSS3** — интерфейс, адаптив, liquid glass, светлая/тёмная темы, печать в PDF.
- **JavaScript (Vanilla)** — вся логика, роутинг, localStorage.
- **Canvas API** — собственные графики без Chart.js.
- **localStorage** — аккаунты и данные (JSON).
- **PWA** — manifest + service worker (офлайн, установка).
- **Web APIs** — Notification, Web Speech (голос), FileReader (CSV).
- **Node.js** — только для локального статик-сервера.

Структура:
```
moi-seif/
├─ index.html     — разметка
├─ style.css      — стили и темы
├─ app.js         — вся логика (≈2300 строк)
├─ manifest.json  — PWA-манифест
├─ sw.js          — service worker (офлайн)
├─ icons/         — иконки приложения
├─ README.md
└─ ZAPISKA.md     — пояснительная записка
```

## ⚠️ Ограничения демо-версии

- Данные хранятся **локально в браузере** (localStorage), а не на сервере. Очистка данных браузера удалит аккаунты.
- Пароли хешируются простой функцией — для учебного проекта достаточно, для реального продукта нужен сервер и bcrypt.
- «Сессии» — локальные аккаунты на одном устройстве, синхронизации между устройствами нет.
