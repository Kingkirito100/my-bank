# 🔐 Мой Сейф — личный бизнес-ассистент

**«Мой Сейф»** — веб-приложение (личный кабинет) для предпринимателя и продавца: финансовый учёт, умный калькулятор прибыли, задачи, цели, календарь и ИИ-ассистент. Полностью **бесплатно**, без сервера и без внешних библиотек — данные хранятся в браузере пользователя.

> Проект по информатике. Всё работает как обычный сайт: открыл ссылку → зарегистрировался → пользуешься.

## ✨ Возможности

## 🤖 Про ИИ (и почему это бесплатно)

- **По умолчанию** работает **локальный ИИ-помощник**: он разбирает запрос по ключевым словам и отвечает на основе ваших реальных данных (баланс, задачи, цели и т.д.). Интернет и API-ключи не нужны — 0 ₽.
- **Опционально** в «Настройках» можно подключить внешний ИИ (OpenRouter с бесплатными моделями или любой OpenAI-совместимый API, например Groq). Ключ хранится только в вашем браузере.

## 🚀 Как запустить

### Вариант 1 — просто открыть файл
Откройте `index.html` в браузере. Всё работает офлайн (кроме внешнего ИИ).

### Вариант 2 — локальный сервер
```bash
# из папки проекта
python3 -m http.server 8080
# или
node server.mjs ./ 8080
```
Затем откройте http://127.0.0.1:8080

### Вариант 3 — демо-данные
На экране входа нажмите **«▶ Посмотреть демо»** или откройте `?demo=1` в адресе.

## 🧱 Технологии

- **HTML5 + CSS3** — интерфейс, адаптивная вёрстка, светлая/тёмная тема.
- **JavaScript (Vanilla)** — вся логика, роутинг, localStorage.
- **Canvas API** — собственные графики (столбцы, кольцевые диаграммы), без Chart.js.
- **localStorage** — хранение аккаунтов и данных (JSON).
- **Node.js** — только для локального/публичного статик-сервера.

Структура:
```
moi-seif/
├─ index.html   — разметка (экран входа + каркас приложения)
├─ style.css    — оформление и темы
├─ app.js       — вся логика (≈1650 строк)
└─ README.md
```

## ⚠️ Ограничения демо-версии

- Данные хранятся **локально в браузере** (localStorage), а не на сервере. Очистка данных браузера удалит аккаунты.
- Пароли хешируются простой функцией — для учебного проекта этого достаточно, но для реального продукта нужен сервер и bcrypt.
- Это SPA без бэкенда: «сессии» — это локальные аккаунты на одном устройстве.
